# 炸金花 · 权威服务端 + 不信任客户端（TypeScript，零运行时依赖）

一个**联机炸金花**（Gin Ki Fa / Three Card Brag）实现：Node 权威服务端 + 浏览器客户端，
WebSocket 手写 RFC 6455 子集，**没有任何第三方运行时依赖**。

它真正想解决的问题不是"能不能玩"，而是 **"客户端凭什么相信服务端"** ——
所以牌桌逻辑只占三成代码，另外七成花在**可验证性**上：多方承诺-揭示种子、投影防泄漏、
客户端第二道算术墙、被抓后不可解除的停手，以及一整套能被人独立重跑的测试与取证。

```
npm install && npm test        # 445 例，固定种子，无时间戳
node netx/serve.ts 8790        # 起房间，浏览器打开它打印的那一行
```

## 30 秒玩起来

```bash
git clone <本仓库地址> && cd <仓库名>
npm install                    # 只装 devDependencies（typescript / vite / @types/node）
node netx/serve.ts 8790        # 或 npm run room
```

服务端会打印：

```
炸金花房间 · ws ws://127.0.0.1:8790 · 页面 http://127.0.0.1:8790/webui/ · 健康检查 http://127.0.0.1:8790/health
```

**打开 `http://127.0.0.1:8790/webui/` 两遍（两个标签页）**，各自填名字、点「连接」，两家到位就自动开局。
根路径 `http://127.0.0.1:8790/` 是另一个入口：单机版（你 + 机器人），与联机链路互不干扰。

**房间流程（M6，产品入口即此流程）**：入座后进入等待——每人点「准备」，全部就绪后**房主**
（在线的最小座位号，掉线即让位）点「开始游戏」才开局；每一局打完，屏幕中央出现结算面板，
**房主**点「继续下一局」才开下一手（其他人看到"等待房主继续"）。断线重连在等待期同样有效；
连接后在名字框里改名再点「连接」，会以新名重连原座位（改名不换座）。

** 局域网多人（M6）**：`node netx/serve.ts 8790 --host 0.0.0.0` —— 横幅会逐行印出局域网地址
（`局域网 ws://192.168.x.x:8790（页面 http://192.168.x.x:8790/webui/）`），把页面链接发给同一网络的朋友即可。
一个进程同时开多张桌：页面头部的「大厅」链接（或 `/lobby`）一键开新桌 / 手输 4 位房间码进入，
码桌地址形如 `ws://host:8790/r/AB3K`；空桌 30 分钟自动回收，码房间数有硬上限（64）防刷。
Windows 上首次 `--host 0.0.0.0` 会弹防火墙放行确认，允许即可。

要求 **Node ≥ 24**（直接用 Node 的类型剥离跑 `.ts`，构建步骤为零）。停服：`Ctrl+C` 或往它的 stdin 输一行 `quit`。

## 防作弊：两道墙

威胁模型是"服务端可能是坏的"——它会篡改权威数字、把别家牌面塞进你的视野、或者用恒定谎言骗过逐帧对账。

**第一道（服务端）**：`src/engine/project.ts` 的投影视图。别人的牌一律 `unknown`；
**你没看牌时连自己的牌都不给你**（这条在早期版本里是漏洞，后来被真机测试撞出来并强制修正）。

**第二道（客户端 `netx/client.ts`）**：每一条下行都要过三关——

| 检查 | 抓什么 |
|---|---|
| `checkDown` schema 校验 | 未知字段、类型/长度越界、协议不符 |
| `checkViewLeak` 投影自检 | 别家牌面、未看牌时自己的牌、揭示前泄露种子 |
| `checkMoney` 纯客户端算术恒等式 | `pot === Σ committed`、**逐座位**同一手内 `chips+committed` 恒定、全桌 `Σ(chips+committed)` 手内恒定 |

第三条是这项目的靶心：`pot` / 我的 `chips` / 我的 `committed` / **别家的** `chips` / 把两者一起改（专门绕过 `pot===Σcommitted`）/ 凭空多塞一个假座位 —— 六种 `patch` 篡改全部要靠客户端**自己算**就能抓到，不需要第二个信息来源。成立区间是量出来的（6 手 × 3 家 = 232 帧逐帧记录，只有 `settled` 那一帧合法地破，故有豁免）。

**被抓之后**：页面明示"这一局不可信"、按钮塌成「已停手」、此后 `act()` 发不出任何行动。
这个停手是**标签页级**的：断开重连、刷新、换房间地址、单机↔联机切换都不解除，**只有关闭该标签页**才干净
（判定结果落在 `sessionStorage` 的 `<prefix>:untrusted`，代码里根本没有清除它的那一行）。

种子方面：服务端先承诺自己的份额 → 各家再交 nonce → 合成 → 局末揭示全部份额并三方互逆核对。
任何一方（包括服务端）事后都改不了这一手的牌。

## 规则口径（v1 `classic`）

- 底注 `ante`、注级 `stake`；闷牌（未看牌）付 `stake`，明牌付 `2×stake`；比牌另付 `2×stake`。
- 牌型：豹子 > 顺金 > 金花 > 顺子 > 对子 > 单张；点数序 A>K>Q>…>2。
- **超时托管 = 自动跟注，付不起才弃**（不是"到点就弃牌"）。
- 无边池、无全押、无退款；下注轮结束由"每家行动计数"判定，不用"圈"这种模糊概念。
- 庄家三档可配：轮庄 / 赢家坐庄 / 输家坐庄。
- 协议子标识 `zjh-m4-1`；默认端口 8790；房间 6 座、最低买入 256。

## 已知边界（不是缺陷清单，是"别拿它当什么"）

- **仍不是一个可上线的产品**：无鉴权（任何人都能入座）、未做公网验收、跨公网部署请自担评估。
  M6 起多房间（房间码路由 + 硬上限 + 空桌回收）与可绑局域网（`--host 0.0.0.0`，横幅印局域网地址）已落地；
  握手有 Origin hostname 等值缓解（防跨站网页连入，**不防 DNS rebinding**；`localhost` 与 `127.0.0.1`
  不做归一 —— 以 IP 访问；IPv6 通配绑定不枚举地址）。Windows 上首次绑 `0.0.0.0` 会触发防火墙放行弹窗。
- `settled` 那一帧对恒等式**合法地破**（池已分发归零而 `committed` 仍记本手投入），所以有豁免；
  由此留下一条已知边界：**跨帧的"恒定谎言"**（每一帧同步篡改）抓不到。最廉价的加固是给守恒量补
  绝对锚点（开局 `chips === buyIn`、第 N 手对齐上一手结算余额），**目前未实现**。
- 等待期的座位板显示「筹码 0 · 投入 0」：服务端在没开局时不下发任何筹码投影（投影里没有的数字
  页面绝不编造），等待期就先空着；开局后即为真实数字。大厅列表每 5 秒自动刷新（页面可见时）。
- `webui/main.ts` 恒 0 覆盖（浏览器入口，无头跑不到，不进覆盖率分母）——它的正确性靠真浏览器验收。
- 等待期（hosted 未开局）座位板显示"筹码 0"：局外的筹码不在任何投影里，页面**不编造数字**；
  买入是否到账以入桌公告与开桌为准。
- 概率与风控语义：这是牌局判定，不是反欺诈模型。
