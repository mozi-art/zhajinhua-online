# M4 · 联机互操作的第一手转写（不是断言，是给复审看的现场记录）
#
# 怎么产生的：进程内起一个真房间（netx/ws.ts + 手写 RFC6455），端口 0 取临时端口；
#   四个客户端全部用 Node 24 内置的全局 WebSocket（undici 实现）经 TCP 回环打进来 —— 对端不是我自己写的客户端。
#   脚本内容 = 每条连接一个"收→喂给 netx/client.ts 会话→回发份额→轮到自己就行动"的循环，走完整手牌后收尾。
#   工装脚本随交付删除；同一件事的可断言版本是 test/netx-ws.test.ts（ws/01…ws/04）。
# 要点：
#   1) 服务端承诺一定排在各家 nonce 之前（下行序列里 commit 先于本家交份额）；
#   2) 丙/丁是在第一局发牌之后才连上的 ⇒ 本局不参与发牌，它们自己的牌面全程 unknown，
#      但仍收到公开投影，并且照样能核对揭示（catchup 会补发承诺）；
#   3) 四家各自独立复算出同一颗种子 = 多方份额合成的那颗（3907236537），且违规列表为空；
#   4) 结算后 pot=0、四笔买入总额守恒（1024）、fault=null。
#
